Open specification · Built environment

Every asset leaves the building with its record.

LoopLedger is an open specification for material passports and recovery evidence. A passport stays with each fixture, panel and chair through every owner. It records how the item came apart and where it went, signed by both parties at every handoff.

Routing

Disposal is the last rung

Before demolition starts, each asset is routed down a fixed ladder. Explicit, versioned rules pick the destination, and every routing decision cites the rule version that governed it.

  1. redeploy
  2. remanufacture
  3. resale
  4. donate
  5. recycle
  6. disposal

Append-only passports

Identity, components, composition, condition and custody. Built on GS1 EPCIS 2.0 events, so nothing is overwritten and nothing is backfilled.

Two-party custody

Every handoff is signed by both sender and receiver, with photos, scale tickets and manifests. Diversion figures come from weighed, signed events, never from self-reported totals.

Jurisdiction rules as code

Local requirements become versioned rules that limit where each asset can go at each site.

Feedback to design

Recovery outcomes are measured for each design revision and each joint. The results flow back to manufacturers, and into design tools as IFC property sets.

The drill

Which revision came apart better, and why?

The repository includes a synthetic drill. One catalog item in two revisions runs through removal, separation and weighing. The drill compares results within a life band, so the older revision's age isn't counted against its joints.

Revision G4

Bonded upholstery. Deliberately older assets in the fixture set.

Revision G5

Mechanically fastened. The bonded joint should account for the difference.

Alignment

A small core, with standards as adapters

The core records LoopLedger's own terms. Standards sit around it as adapters and classifications, so the core doesn't depend on any one region's codes.

  • EventsGS1 EPCIS 2.0 and CBV 2.0 (ISO/IEC 19987, 19988)
  • PassportsUNTP Digital Product Passport; EU DPP under ESPR
  • IdentifiersISO/IEC 15459, carried as GS1 Digital Link
  • Waste codesRegional codes, such as EU Waste Framework Directive R/D, as classifications beside each route
  • Design dataIFC property sets; bSDD class references (IFC 4.3, NAAKT 2.5); EPD data per ISO 22057 (planned)
  • CarbonEN 15804 EPDs, with measured end-of-life data for modules C and D (planned)
  • CircularityISO 20887 for design for disassembly; ISO 59020 (planned)
